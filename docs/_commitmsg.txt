Deploy bugs found and fixed:
- run_remote returned from inside the chunk loop, so only the first SSM batch ran
  and the 830KB app payload arrived as its first 66KB (corrupt tarball)
- the payload is one long base64 string that the request chunker splits
  mid-string, so it is shipped as explicit 6KB appends; payload also cut from
  830KB to 152KB by dropping the retired synthetic weld samples
- default VPC security group allows only SSH: the service was healthy on
  localhost but refused external connections, so a dedicated SG with port 80
- AssociatePublicIpAddress and BlockDeviceMappings are not accepted at top level
  in this API version, and the COOL G4 snapshot is 50GB so the 20GB volume
  override was fatal
- the Windows cp1252 console crashed printing box-drawing characters

Endpoint left DOWN deliberately: 20 days always-on would be about $34.6 and
would blow the $25 cap. docs/DEPLOYMENT.md documents the on-demand schedule for
submission and judging. All AWS spend to date is under $1.
